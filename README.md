# AI Learning Management System (AI-LMS)

This is a comprehensive full-stack repository designed to build an AI-powered Learning Management System featuring personalized tutoring, adaptive learning paths, quiz generation, and active study assistance.

## Directory Structure

- `/frontend` - Next.js 14 Web Application (TypeScript, Tailwind CSS)
- `/backend` - FastAPI Python Server (Python 3.11, PostgreSQL)
- `/rag` - LlamaIndex Retrieval-Augmented Generation (RAG) pipeline
- `/agents` - LangGraph multi-agent cognitive architecture
- `/docker` - Containerization assets including Dockerfiles and docker-compose files

## Stack Overview
- **Frontend**: Next.js 14, React, Tailwind CSS, TypeScript
- **Backend**: FastAPI, Python 3.11, SQLAlchemy, Uvicorn
- **Vector DB**: Pinecone
- **Cognitive Agents**: LangGraph, LangChain, OpenAI GPT-4
- **Knowledge Base (RAG)**: LlamaIndex
- **Infrastructure**: Docker & Docker Compose, PostgreSQL
